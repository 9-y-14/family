# 家庭全能管家

> 综合性家庭管理平台，涵盖记账、证件、应急、成长、种植六大模块 | 纯前端 · 本地存储 · 零依赖部署

## 项目简介

**家庭全能管家**是一个纯前端静态网页应用，为家庭提供一站式管理工具。分为两大分区、六个子模块，覆盖家庭生活的主要场景。所有数据存储在浏览器本地（localStorage），无需服务器、无需数据库、无需注册，开箱即用。

### 分区与模块

| 分区 | 模块 | 功能简介 |
|------|------|----------|
| 🔒 **居家安全资产台账区** | 人情往来记账台账 | 送礼/收礼双向记录，CSV导入，ECharts多维图表分析 |
| | 证件&保单到期提醒 | 证件与保单有效期管理，到期自动预警，支持自定义预警天数 |
| | 家庭药品检查表 | 家庭常备药品效期跟踪，到期/已过期状态自动提示 |
| 💕 **家庭温情成长互动区** | 家庭真心话·破冰站 | 匿名/实名吐槽心声，家人回应互动，关键词情绪分析 |
| | 心愿储蓄罐 | 心愿许愿墙，点赞投票，随机抽取心愿，完成心愿墙展示 |
| | 阳台种植争霸赛 | 虚拟植物养成游戏，浇水/施肥/晒太阳/修剪，成长阶段升级，周排行榜 |

## 功能特性

### 人情往来记账台账
- 📥 **CSV文件导入**：支持 UTF-8 编码的账单 CSV 批量导入
- 🧹 **智能数据清洗**：自动过滤空值、负金额、错误日期格式
- ✋ **手动录入**：快速添加单笔账单，支持收支双方向
- 🔍 **多维筛选查询**：按年份、事件类型、收支方向筛选；按月/年查询汇总
- 📊 **5大图表可视化**：月度收支趋势折线图、事件类型占比饼图、地区金额柱状图、季节分析图、收支方向对比图
- 💾 **历史记忆**：自动记录往来对象、地区等输入历史，方便补全

### 证件&保单到期提醒
- 📁 **有效期管理**：支持身份证件、房产证明、驾驶证件、医疗保险、人寿保险、车辆保险等多种类型
- ⚠️ **智能预警**：每项可独立设置预警天数（默认90天），到期前自动标红提醒
- 📅 **天数计算**：自动计算剩余有效天数，一目了然
- 🔄 **分类筛选**：按证件类型、到期状态（正常/预警/已过期）筛选

### 家庭药品检查表
- 💊 **药品效期追踪**：记录药品名称、存放位置、有效期
- 🔴 **状态提醒**：自动标注即将到期（≤30天）和已过期药品
- 📋 **检查清单**：支持勾选已检查项，方便定期家庭药品盘点

### 家庭真心话·破冰站
- 💬 **匿名/实名倾诉**：家庭成员可选择匿名或实名发表心声
- 🗣️ **吐槽与期望**：记录问题（problem）和期望（request），促进沟通
- ✅ **回应交互**：家人可直接在记录下回应，促进理解
- 📈 **关键词云**：自动分析高频情绪关键词

### 心愿储蓄罐
- 🌟 **许愿墙**：家庭成员发表心愿，可匿名或署名
- ❤️ **点赞互动**：家人为彼此的心愿点赞投票
- 🎲 **随机抽取**：一键随机抽取心愿，增加趣味性
- 🏆 **完成墙**：已完成的心愿会上墙展示，记录完成日期和照片

### 阳台种植争霸赛
- 🌱 **虚拟种植**：多种植物可选，从种子到结果的完整成长阶段（🌱→🌿→🪴→🌳→🌸→🍎）
- 👨‍👩‍👧‍👦 **家庭成员赛道**：每人选择一种植物参与争霸
- 🧑‍🌾 **照料互动**：浇水、施肥、晒太阳、修剪 4 种照料方式，每次增加不同成长值
- 🏆 **周排行榜**：每周统计照料次数，榜首获得"最佳种植者"称号

## 快速开始

### 本地运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖或启动服务器。

```bash
# 克隆仓库
git clone https://github.com/9-y-14/family.git
cd family

# 用浏览器打开
start index.html        # Windows
open index.html         # macOS
```

### 在线部署

项目为纯静态文件，可一键部署到任意静态托管平台：

- **GitHub Pages**：Settings → Pages → 选择分支 → Save
- **Cloudflare Pages**：连接仓库，无需构建命令，输出目录设为 `/`
- **Vercel**：导入 Git 仓库，自动检测部署
- **Netlify**：拖拽文件夹即可上线
- 阿里云 OSS / 腾讯云 COS 等对象存储

## CSV 数据格式

### 人情往来台账

```csv
日期,往来对象,事件类型,收支类型,金额,所在地区,备注
2024-01-15,张三,喜事,支出,500,北京,同事结婚
2024-03-20,李四,喜事,收入,2000,上海,好友随礼
```

- 事件类型：`喜事` / `白事` / `节日送礼`
- 收支类型：`支出` / `收入`

### 证件&保单

```csv
登记日期,证件/保单名称,证件类型,保管位置,生效日期,到期日期,备注,预警天数
2023-01-01,身份证-张三,身份证件,书房抽屉,2023-01-01,2033-01-01,长期有效,365
```

- 证件类型：`身份证件` / `房产证明` / `驾驶证件` / `医疗保险` / `人寿保险` / `车辆保险`
- 预警天数为可选列，默认 90 天

## 数据安全

- ✅ 所有数据仅在浏览器本地 localStorage 中存储
- ✅ 不上传到任何远程服务器
- ✅ OCR 识别在浏览器本地运行，图片不会上传
- ✅ 无第三方追踪、无用户画像
- ⚠️ 清除浏览器缓存会导致数据丢失，建议定期导出 CSV 备份
