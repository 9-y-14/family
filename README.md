# 家庭全能管家

> 记账 · 证件 · 心愿 · 沟通 综合管理平台 | 纯前端 · 本地存储 · 开箱即用

---

## 一、项目介绍

### 1.1 项目背景

现代家庭生活中，资产管理（账务往来、证件保险、家庭药品）与情感互动（沟通表达、心愿实现、亲子游戏）往往分散在不同工具中，缺乏统一管理。**家庭全能管家**应运而生，旨在为家庭提供一站式的资产安全与情感互动综合管理平台。

### 1.2 项目概述

**家庭全能管家**是一个综合性家庭管理网页应用，按功能分为**两大分区、六个子模块**，覆盖家庭资产安全与情感互动的核心场景。支持"**未登录预览示例数据**"和"**登录后使用家庭私有数据**"两种模式，所有数据默认存储在浏览器本地，安全无忧。

### 1.3 核心功能

| 分区 | 子模块 | 功能简介 |
|------|--------|----------|
| 🔒 居家安全资产台账区 | 人情往来记账台账 | 送礼（支出）/收礼（收入）双向账单管理。支持 CSV 批量导入、手动录入、数据清洗。6 个 ECharts 图表（月度走势、事件占比、地区排行、四季对比、收支对比、类型占比） |
| | 证件&保单到期提醒 | 身份证件、房产证明、驾照、各类保险等有效期管理。每条记录可独立设置预警天数，到期前自动标红。支持按类型/状态筛选 |
| | 家庭药品检查表 | 常备药品的采购日期与保质期跟踪。每半年自动提醒全量盘点，自动生成药品缺口采购清单，支持药品名称搜索防止重复购买 |
| 💕 家庭温情成长互动区 | 家庭真心话·破冰站 | 匿名/实名说出心声（道歉、委屈、感谢…）。家人可回应互动，自动聚合高频话题关键词排序 |
| | 心愿储蓄罐 | 许愿墙、点赞投票、检查过期心愿、完成心愿并上传纪念照片建成「心愿完成墙」 |
| | 阳台种植争霸赛 | 虚拟植物养成游戏。每个家庭成员种一棵植物，通过浇水/施肥/晒太阳/修剪照料，植物从种子到结果自动成长。每周照料次数最多者当选最佳种植者，可抽取心愿储蓄罐中的心愿 |

> ⚠️ 资产台账区仅「家庭管理者」验证后可访问和操作；普通成员不可见。

### 1.4 用户体系

```
未登录（游客）
  └── 全站展示示例数据，可浏览所有功能

登录用户
  ├── 家庭管理者（admin）
  │     ├── 可访问居家安全资产台账区（需输入管理者验证码）
  │     ├── 台账区数据的新增/修改/删除
  │     ├── 管理家庭成员、查看邀请码
  │     └── 使用温情成长互动区
  └── 普通成员（member）
        ├── 不可见资产台账区
        └── 可使用温情成长互动区全部功能
```

- 创建家庭账号的注册人自动成为「**家庭管理者**」
- 管理者创建家庭后获得 8 位邀请码，家人凭邀请码加入
- 访问台账区时需验证管理者设置的独立验证码（有效期 30 分钟）
- 各家庭数据物理隔离，互不可见

### 2.4 技术特点

- **纯前端架构**：无需搭建后端服务器，所有逻辑在浏览器端完成
- **零安装依赖**：所有第三方库通过 CDN 引入，无需 npm install
- **本地存储**：数据留在用户浏览器，保障隐私安全
- **响应式设计**：基于 Bootstrap 5 栅格系统，适配 PC/平板/手机
- **模块化组织**：每个功能模块独立 .js 文件，易于维护和扩展
- **可选云部署**：支持 Cloudflare Pages 部署，可配合 D1 数据库实现云存储

## 三、运行说明

### 3.1 环境要求

| 环境 | 最低要求 |
|------|----------|
| 浏览器 | Chrome 90+ / Edge 90+ / Firefox 88+ / Safari 14+ |
| 网络 | 需要网络连接加载 CDN 资源（首次加载后浏览器可缓存） |
| 系统 | Windows / macOS / Linux 均可 |
| 其他 | 无需安装 Node.js 或任何运行时环境（仅本地开发可选） |

### 3.2 本地运行

直接用浏览器打开 `index.html` 即可，无需任何服务器或依赖安装。

```bash
# 1. 克隆仓库
git clone https://github.com/9-y-14/family.git
cd family

# 2. 直接打开（二选一）
start index.html        # Windows
open index.html         # macOS

# 3. 或使用本地服务器（可选，解决跨域问题）
npx serve .             # 使用Node.js本地服务
python -m http.server 8080  # 使用Python本地服务
```

### 3.3 在线部署

项目为纯静态文件，支持一键部署到任意静态托管平台：

| 平台 | 部署方式 | 构建命令 | 输出目录 |
|------|----------|----------|----------|
| **Cloudflare Pages** | 连接 Git 仓库，设置 D1 绑定 | 留空 | `/` |
| **GitHub Pages** | Settings → Pages → 选择分支 | — | — |
| **Vercel** | 导入 Git 仓库或拖拽文件夹 | 留空 | `/` |
| **Netlify** | 导入 Git 仓库或拖拽文件夹 | 留空 | `/` |

#### Cloudflare Pages + D1 部署配置（进阶）

如需启用云端数据存储，按以下步骤配置：

```bash
# 1. 创建 D1 数据库
npx wrangler d1 create family-db

# 2. 更新 wrangler.toml 中的 database_id

# 3. 初始化数据表
npx wrangler d1 execute family-db --remote --file=./schema.sql

# 4. 在 Cloudflare Pages Dashboard 绑定 D1：
#    Settings → Variables → D1 Database Bindings
#    变量名: DB → 选择: family-db
```

## 四、附录

### 4.1 CSV 数据格式

#### 人情往来台账

```csv
日期,往来对象,事件类型,收支类型,金额,所在地区,备注
2024-01-15,张三,喜事,支出,500,北京,同事结婚
2024-03-20,李四,喜事,收入,2000,上海,好友随礼
```

- 事件类型：`喜事` / `白事` / `节日送礼`
- 收支类型：`支出` / `收入`

#### 证件&保单

```csv
登记日期,证件/保单名称,证件类型,保管位置,生效日期,到期日期,备注,预警天数
2023-01-01,身份证-张三,身份证件,书房抽屉,2023-01-01,2033-01-01,长期有效,365
```

- 证件类型：`身份证件` / `房产证明` / `驾驶证件` / `医疗保险` / `人寿保险` / `车辆保险`
- 预警天数为可选列，默认 90 天

### 4.2 数据安全

- ✅ 所有数据存储在浏览器 localStorage，不上传到任何服务器（未启用 D1 时）
- ✅ 登录会话存储在 sessionStorage，关闭浏览器即登出
- ✅ 无第三方追踪、无用户画像
- ⚠️ 清除浏览器缓存会导致数据丢失，建议定期导出 CSV 备份
