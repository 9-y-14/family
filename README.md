# 家庭人情随礼账单统计平台

> 大数据期末作业 | 纯前端静态网页 | HTML5 + Bootstrap5 + JS + Tesseract.js(OCR) + PapaParse + ECharts5

## 项目简介

一个纯前端的家庭人情账单统计分析工具，包含**送礼账单**和**收礼账单**两个模块。所有数据在浏览器本地处理，**无后端、无服务、无数据库**，可直接上传 GitHub 并使用 Cloudflare Pages 一键部署上线。

### 模块说明

| 页面 | 文件 | 功能 |
|------|------|------|
| **送礼账单** | `index.html` | 记录向外支出的随礼账单，CSV导入/手动录入 |
| **收礼账单** | `income.html` | 记录收到的礼金账单，支持**礼簿图片OCR识别**、CSV导入、手动录入 |

## 技术栈

| 技术 | 用途 |
|------|------|
| **HTML5** | 页面结构 |
| **Bootstrap 5** (CDN) | 响应式UI框架 |
| **原生 JavaScript** | 数据清洗、聚合统计、业务逻辑 |
| **Tesseract.js 5** (CDN) | 礼簿图片OCR文字识别（纯前端） |
| **PapaParse 5** (CDN) | CSV文件解析 |
| **ECharts 5** (CDN) | 数据可视化图表 |

## 功能特性

### 送礼账单（index.html）
- 📥 **CSV文件导入**：支持上传UTF-8编码的CSV账单文件
- 🧹 **数据清洗**：自动删除空值、负数金额、错误日期格式
- 📅 **日期标准化**：统一格式为 `YYYY-MM-DD`
- ✋ **手动添加**：支持表单手动录入单条账单
- 🔍 **关键字搜索**：按人名/地区/备注模糊搜索
- 📊 **4个图表**：月度折线图、事件饼图、地区柱状图、四季柱状图

### 收礼账单（income.html）
- 📸 **礼簿图片OCR导入**：拍摄/上传礼簿照片，Tesseract.js 自动识别文字并解析为收礼记录
- 📥 **CSV文件导入**：与送礼页面相同的CSV导入能力
- ✋ **手动添加**：表单录入
- 🔍 **关键字搜索**：按人名/地区/备注模糊搜索
- 📊 **4个图表**：月度折线图、事件饼图、地区柱状图、送礼人排行

### 聚合统计（前端JS批量运算）
- 年度总礼金统计
- 月度消费走势分析
- 事件类型开销占比
- 各地区礼金花费排行
- 送礼人金额排行（收礼页面专属）

## OCR图片识别说明

收礼页面支持通过拍照或上传礼簿图片来导入数据：

1. 点击"选择礼簿照片"选择图片（或拍照）
2. 预览确认后点击"开始识别"
3. Tesseract.js 在浏览器本地进行 OCR 文字识别
4. 系统自动解析识别文本，提取收礼记录
5. 确认无误后点击"确认导入"

**提示：** 图片越清晰、文字越规整，识别准确率越高。建议礼簿使用打印体或工整手写体。

## 快速开始

### 方式一：本地运行
直接用浏览器打开 `index.html` 或 `income.html` 即可，无需任何服务器。

### 方式二：Cloudflare Pages 部署
1. 将项目推送到 GitHub 仓库
2. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)
3. 进入 `Workers & Pages` → `Create` → `Pages`
4. 连接 GitHub 仓库，选择本项目的仓库
5. 构建设置：
   - 构建命令：留空
   - 输出目录：`/` (根目录)
6. 点击部署即可

### 方式三：任意静态托管
由于项目是纯静态文件，可部署到任何静态托管服务：
- GitHub Pages
- Netlify
- Vercel
- 阿里云OSS
- 腾讯云COS

## 数据安全

- ✅ 所有数据仅在浏览器内存中处理
- ✅ 不会上传到任何服务器
- ✅ OCR识别在浏览器本地运行，图片不会上传
- ✅ 刷新页面后数据会丢失
- ✅ 无任何第三方数据追踪
